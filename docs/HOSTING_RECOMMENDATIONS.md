## 📝 Пошаговый план развертывания (Railway)

### Шаг 1: Подготовка репозитория

```bash
# Убедитесь что у вас есть:
- .gitignore (не коммитить .env файлы)
- Правильные package.json и requirements.txt
```

### Шаг 2: Railway Setup

1. Перейдите на https://railway.app
2. Sign up через GitHub
3. New Project → Deploy from GitHub repo
4. Выберите ваш репозиторий DONOSTI STRATEGIA
5. Railway создаст 2 сервиса: Frontend и Backend

### Шаг 3: Добавить MongoDB

1. В проекте Railway: New → Database → MongoDB
2. Railway создаст MongoDB и выдаст `MONGO_URL`
3. Эта переменная автоматически доступна Backend

### Шаг 4: Настроить переменные окружения

**Backend Service:**
```
MONGO_URL=<автоматически от Railway>
DB_NAME=donosti_strategia_prod
CORS_ORIGINS=https://donostistrategia.com
SMTP_EMAIL=noreply@donostistrategia.com
SMTP_PASSWORD=your-app-password
```

**Frontend Service:**
```
REACT_APP_BACKEND_URL=https://your-backend.railway.app
```

### Шаг 5: Custom Domain

1. Settings → Networking → Custom Domain
2. Добавьте `donostistrategia.com`
3. Настройте DNS у регистратора:
   ```
   A     @     [Railway IP]
   CNAME www   [Railway domain]
   ```
4. SSL настроится автоматически

### Шаг 6: Deploy

- Каждый push в GitHub = автоматический деплой
- Мониторьте логи в Railway dashboard
- Проверьте работу сайта

**Готово!** ✅
